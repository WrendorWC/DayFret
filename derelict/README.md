# DERELICT: Escape from Station Echo

A short Sierra-style (Space Quest-ish) graphical adventure. ~30 minutes.

You are Dex Murphy, sanitation engineer. Your shuttle died, and the only
dock in range is a research station that's been silent for fourteen months.
Find power, find out what happened, and get off the station.

## Play

Double-click `play.command`, or open `index.html` in any browser.
No build, no dependencies — one HTML file and one JS file.

## Controls

- Click a verb (WALK / LOOK / USE / TAKE / TALK), then click the world
- Keys 1–5 select verbs; right-click cycles them
- Arrow keys / WASD also walk; click the floor to walk there
- Click an inventory item, then click a target to use it on something
- H or the HINT button if you're stuck
- Progress autosaves; there are several classic Sierra deaths (the game
  just resets the scene)

Max score: 100 points.
